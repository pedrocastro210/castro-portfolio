## O que é isso

Este repositório é o meu portfólio — e também é a prova do que eu entrego.
A home não é um mockup estático: é o mesmo nível de acabamento (animação
scroll-driven, transições, atenção a detalhe) que eu construo pros meus
clientes. E o catálogo de projetos (`/projetos`) não mostra prints — abre o
site real do cliente, rodando de verdade, dentro da própria página.

## Para desenvolvedores

Quer rodar localmente ou entender a arquitetura por baixo?

```bash
npm install
npm run dev      # servidor de desenvolvimento
npm run build    # build de produção (tsc + vite build)
npm run lint      # oxlint
npm run preview  # preview do build de produção
```

Documentação técnica completa (rotas, como adicionar um novo demo ao
catálogo, deploy) em **[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)**.
